# ZeeZee — Instaladores

Este repositorio contiene únicamente los **instaladores** de ZeeZee, el hub de mensajería de [Zeeben Labs](https://damelm.github.io). El código fuente se mantiene privado.

## Descargar e instalar (Windows)

1. Entrá a [Releases](https://github.com/damelm/zeezee-installers/releases) y descargá el `.exe` de la última versión.
2. Ejecutalo. La instalación es **por usuario** y **no requiere permisos de administrador**.

El instalador todavía no está firmado digitalmente, así que Windows puede mostrar una advertencia de seguridad ("Editor desconocido"). Se continúa con **Ejecutar** (o, si aparece la pantalla de SmartScreen, **Más información → Ejecutar de todas formas**).
